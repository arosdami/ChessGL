\# ChessGL



Klasszikus sakkjáték C nyelven, modern OpenGL 3.3 Core Profile grafikával.



\## Készítette



\- \*\*Név:\*\* Aros Damjan

\- \*\*Tantárgy:\*\* 3D modellezés és játékfejlesztés

\- \*\*Oktató:\*\* Dr. Mileff Péter



\## Technológiák



\- \*\*Nyelv:\*\* C (C11)

\- \*\*Grafika:\*\* OpenGL 3.3 Core Profile (saját shaderek)

\- \*\*Ablakkezelés:\*\* GLFW

\- \*\*OpenGL betöltő:\*\* GLAD
